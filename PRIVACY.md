# 🛡️ NEXGEN Internet Guardian — Privacy Policy

**Effective Date:** October 15, 2026

NEXGEN Dev Studio respects your privacy. This Privacy Policy explains how NEXGEN Internet Guardian handles information while monitoring your Windows network connection.

## 1. Information Collection

NEXGEN Internet Guardian is designed as a local Windows network monitoring utility. It does not require an online account for its core monitoring functionality.

The application is not designed to collect personal information such as:

- Your name or personal identity information
- Passwords or account credentials
- Browser history or search history
- Websites you visit or browsing content
- Personal files, documents, or communications

## 2. Network Information

To provide its monitoring features, the application may access network information available through Windows, including:

- Local IP address
- Network adapter name
- Connection type, such as Wi-Fi or Ethernet
- Ping measurements
- Download and upload activity reported by Windows network statistics
- Internet connection status

This information is used to display network status and diagnostics.

## 3. Data Transmission

The application is designed not to transmit local network monitoring information to NEXGEN Dev Studio.

Network connectivity checks may communicate with external network destinations to determine connectivity and measure ping. These checks are part of the monitoring functionality and are distinct from sending monitoring data to NEXGEN Dev Studio.

## 4. Local Settings and Storage

Application settings may be stored locally on your Windows computer to remember your preferences, including notification settings.

Local storage behavior may depend on the installed version of the application.

## 5. Notifications

NEXGEN Internet Guardian provides configurable network notifications. Users can enable or disable supported notifications through the application's Settings.

Notification preferences control alerts; they do not necessarily disable background network monitoring.

## 6. Third-Party Services

The core monitoring functionality does not require a NEXGEN online account or cloud service.

Windows networking components and any included third-party libraries may operate under their respective terms and privacy practices.

## 7. Data Sharing and Sale

NEXGEN Dev Studio does not sell users' personal information.

The application is designed not to send its local network monitoring information to NEXGEN Dev Studio.

## 8. Children's Privacy

NEXGEN Internet Guardian is not designed to collect personal information from children.

## 9. Security

Users should keep Windows and the application updated and download releases from the official project page.

No software or data-storage method can be guaranteed to be completely secure.

## 10. Changes to This Policy

This Privacy Policy may be updated when the application or its data practices change. Updated versions will be published in the project repository.
