# 🛡️ NEXGEN Internet Guardian

**A lightweight Windows network monitoring utility by NEXGEN Dev Studio.**

NEXGEN Internet Guardian helps you keep track of your internet connection using live network information, connection-status indicators, and configurable notifications.

## ✨ Features

- **Network monitoring** — view connection information and network status.
- **Ping monitoring** — monitor response times to help identify latency changes.
- **Connection-status indicators** — show statuses such as Connected, Slow Network, Limited Connection, or No Internet.
- **Network adapter information** — view relevant information about the active adapter.
- **Local network information** — display local IP information when available.
- **Configurable notifications** — enable or disable supported notifications in Settings.
- **System-tray access** — keep the utility accessible from the Windows notification area.
- **About screen** — access the repository, Privacy Policy, License, and contact details.
- **Local preferences** — app settings are saved on the device.

> **Note:** Download/upload activity reported by network-adapter counters is not the same as an internet speed test and does not measure maximum connection speed.

## 💻 System Requirements

- Windows 10 (64-bit) or Windows 11.
- A supported network adapter.
- An active network connection for live internet monitoring.
